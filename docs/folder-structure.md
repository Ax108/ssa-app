# Folder structure

Paths are relative to the **Astrax-sadhan-sangha-app** repository root.

Product code lives under **`src/`** (not Expo Router’s `app/` directory). Native shells `android/` and `ios/` are generated by prebuild.

## Repository root

```
Astrax-sadhan-sangha-app/
├── README.md                 # Project hub
├── docs/                     # This documentation set
├── package.json              # Scripts, deps, engines
├── app.json                  # Expo app config (name, ids, plugins)
├── index.ts                  # Metro entry → registerRootComponent
├── babel.config.js
├── metro.config.js
├── tsconfig.json             # Path aliases (@features, @store, …)
├── tsconfig.no-tests.json    # Strict app-only typecheck (tsc:app)
├── eslint.config.js
├── jest.config.js / jest.setup.js
├── plugins/                  # Expo config plugins (native tweaks)
│   └── withAndroidLinkingQueries.js
├── assets/                   # App icon, splash, adaptive icon, logos
├── src/                      # All application TypeScript / UI
├── android/                  # GENERATED — do not hand-edit for features
└── ios/                      # GENERATED — macOS / Xcode
```

### Root rules

| Area | Rule |
|------|------|
| Config at root | Keep thin: Expo, Metro, ESLint, Jest, entry `index.ts` |
| `plugins/` | Expo config plugins only (e.g. Android intent queries) |
| `assets/` | Store branding binaries referenced from `app.json` |
| `android/` / `ios/` | Treat as output of `bun run prebuild`; regenerate when native deps/plugins change |
| `docs/` | Markdown for humans; no runtime imports |

## `src/` layout

```
src/
├── App.tsx                   # Root React tree (providers, splash gate)
├── appStore/                 # Zustand store (global — not under features/)
│   ├── appStore.ts
│   ├── navbarSlice.ts
│   ├── contentSlice.ts
│   └── contentController.ts  # Boot: AsyncStorage → sync/CDN (awaited at splash)
├── constants/                # palette, theme, CDN URLs
├── assets/
│   └── json/                 # Seed config.json + en.json (offline fallback)
├── features/                 # One folder per product area
│   ├── app/                  # Splash, fonts, AppRoot shell
│   ├── navigation/           # Stacks, tab bar, top navbar, navigationRef, helpers/
│   ├── home/                 # GurujiRow, HomeHero, HomeScreen
│   ├── ashram/
│   ├── satsang/
│   ├── gallery/
│   └── contact/
├── shared/                   # Cross-feature UI, hooks, utils, types, APIs
│   ├── components/           # FollowUsSection, SSADivider, AppFooterStrip, …
│   ├── hooks/                # e.g. useNavigateTab
│   ├── helpers/
│   ├── serviceCalls/         # oxyApi (native fetch)
│   ├── types/
│   └── utils/                # assetUrl (markdown + YT), openUrl, logger, formatConfig

```

## Feature module conventions

Each feature under `src/features/<name>/` should stay self-contained:

```
features/home/
├── HomeScreen.tsx            # Screen entry used by navigation
├── components/               # Home-only UI pieces
└── data/                     # Optional local meta (not CDN JSON)
```

| Put here | Do not put here |
|----------|-----------------|
| Screen UI for that domain | Global Zustand slices → use `appStore/` |
| Feature-only components | Shared buttons/images → `shared/components/` |
| Feature path aliases (`@home/*`) | Native Android/iOS edits |

Same pattern for `ashram`, `satsang`, `gallery`, `contact`. Navigation chrome stays in `features/navigation/`.

## `appStore/` (global state)

- **`navbarSlice`** — active route title for **bottom tab** highlight (top bar is brand-only).
- **`contentSlice`** — `loaded`, `version`, `config`, `texts`.
- **`contentController`** — async boot (cache → sync/CDN); awaited from `App.tsx` splash.

Do not relocate the store into `features/`.

## `shared/` vs `features/`

| Kind of code | Location |
|--------------|----------|
| Used by 2+ features | `src/shared/…` |
| Single-feature UI | `src/features/<feature>/…` |
| HTTP helpers for CDN | `src/shared/serviceCalls/` |
| Types for config/texts | `src/shared/types/` |
| Theme / CDN constants | `src/constants/` |

## Path aliases (`tsconfig.json`)

| Alias | Maps to |
|-------|---------|
| `@store/*` | `src/appStore/*` |
| `@features/*` | `src/features/*` |
| `@shared/*` | `src/shared/*` |
| `@constants` / `@constants/*` | `src/constants` |
| `@home/*`, `@ashram/*`, … | Matching feature folders |
| `@navigation/*` | `src/features/navigation/*` |
| `@src/*` | `src/*` |
| `@/*` | Repo root |

Prefer aliases over deep relative `../../../` imports.

## Tests

- Unit / screen tests live under **`src/tests/`** (current layout).
- Run via `bun test` / `bun verify`.
- Details: [testing.md](./testing.md).

## What not to add

- Expo Router `app/` routes — this project uses React Navigation.
- Feature logic inside `android/` or `ios/`.
- Parallel roots like `src/screens`, `src/components` at the top of `src/` — use `features/` and `shared/`.
